# 햄스터 로봇 v0.7 — 출력 부품과 구매·조립 안내

## 1. 바로 전부 출력해도 되는가?

**v0.6을 그대로 전부 출력하는 것은 권하지 않는다.** 닫힌 가이드의 삽입 경로, 서보 마운트와 지지대의 겹침, 모터 마운트 너트 공간, 게이트/캐리어의 미확정 결합을 이번 v0.7에서 수정했다.

**v0.7 STL은 출력용 부품별로 분리했지만, 실물 조립·주행까지 인증된 완제품은 아니다.** 먼저 `stl_test_first`의 두 부품을 출력하고, 사용할 모터·서보·캐스터·배터리를 실측한 뒤 본체 출력을 결정한다. 이 안내를 읽지 않고 13종 전체를 일괄 출력하지 않는 것이 좋다.

검증 범위는 CAD 형상, 부품 분리, 명목 체결 공간과 가동 간섭이다. 실제 프린터 슬라이싱/G-code, 출력 강도, 부품 호환성, 무게중심은 미확정이다. 기존 v0.1~v0.6 파일은 보존되어 있다. **v0.6과 v0.7의 부품을 섞어 조립하지 않는다.**

## 2. 연결부에서 바꾼 점

| 기존 문제 | v0.7 처리 |
|---|---|
| 가이드가 위아래 다리로 막혀 슬리브 삽입이 어려움 | 윗다리를 분리형 캡으로 변경. 가동부를 먼저 끼운 뒤 캡 2개 체결 |
| UP 슬리브와 기존 윗다리의 여유 부족 | 가이드 상단을 높이고 탈착 캡 아래에 이동 공간 확보 |
| 게이트와 캐리어가 별도인데 확실한 고정법이 없음 | 한 개의 `gate_slider`로 통합. 접착제나 억지 끼움 불필요 |
| 가로보가 슬리브 통로 일부를 다시 막음 | 가동부를 통합한 뒤 양쪽 가이드 통로를 전체 관통해 재생성 |
| 서보 마운트 팔이 지지 기둥과 겹침 | 지지대 높이를 마운트 받침면에 맞추고 체결공 추가 |

| 링크 끝이 캐리어 빔과 닿을 수 있음 | 링크 러그 높이·옆 위치와 링크 평면 조정. 게이트 이동량은 그대로 |
| 모터 귀 아래의 좁은 기둥이 너트/볼트를 막음 | 두꺼운 체결 블록, 옆으로 넣는 M3 너트 자리, 충분한 관통 깊이 |
| 트레이와 캐스터가 서로 연결되어 정비가 번거로움 | 배터리 트레이는 데크 4점에 독립 체결 |
| 일부 나사/인서트 규격 미확정 | 상·하부, 뚜껑, 데크, 모터, 트레이, 후방 체결을 일반 M3 너트 기준으로 정리 |
| 데크 2.5 mm에 모터와 배터리가 매달림 | 데크 3.5 mm, 받침 4.5 mm로 보강. 강도 실물 시험은 여전히 필요 |

Ø56 디스크, OPEN-BOTTOM, 곡선 funnel, 후방 고정 차단막의 포획 형상과 게이트 이동량 11.7 mm는 유지했다. 새 러그에 맞춰 서보 장착 높이는 기존보다 3.5 mm 올라갔다.

## 3. 프린터로 출력할 파일

`stl_print/`에는 **출력할 플라스틱 부품만** 있다. 모터, 바퀴, 서보, 배터리, 보드, 금속 나사, 샘플 디스크는 포함하지 않는다. 조립 상태 전체를 합친 STL은 제공하지 않는다.

SG90이라는 이름만 보고 치수가 맞는다고 판단하면 안 된다. 제조사 [TowerPro SG90 Digital](https://towerpro.com.tw/product/sg90-7/)의 전체 외형 표기는 23×12.2×29 mm이며, 몸체·귀·축을 구분해 실물과 CAD를 대조해야 한다. 클램프는 제품별 귀/전선 간섭까지 확정한 설계가 아니다.

**캐스터는 v0.6의 Ø16/Y=-43 미리보기에서 Ø12/Y=-40으로 변경했다.** 구와 후방 하부 구조, 브래킷 세로벽과 장착 볼트 공간을 분리하기 위한 기본 포락 변경이다. 실제 상용 캐스터가 정해지면 이 값부터 다시 맞춘다. 외형이 큰 하우징을 구 미리보기로 대신 검증할 수는 없다.

### 구조용 나사·너트 — 기본값 기준

|---|---:|---|

| M3 접시머리 ×10 | 6 | 뚜껑4 + 후면 캐스터 브래킷2 |
| M3 소켓/팬머리 ×10 | 4 | 데크 → 셸 받침4 |
| M3 소켓/팬머리 ×12 | 8 | 모터 마운트4 + 배터리 트레이4 |
| 일반 M3 육각 너트 | **22** | 위 구조용 M3 체결 전체 |
| M2.5 ×10 | 6 | 가이드 캡2 + 서보 받침 팔2 + 서보 클램프2 |
| M2.5 ×14 링크 핀용 볼트 | 2 | 혼↔연결봉, 캐리어 러그↔연결봉 |
| 링크 핀용 M2.5 잠금 너트 | 2 | 핀이 풀리지 않도록, 실제 높이 확인 |
| M2.5 얇은 와셔/부싱 | 최소4 | 링크 양쪽 축의 회전면. 실제 축방향 유격 조정용 |
| Ø2.8 이상 내경의 링크 스페이서 | 1세트 | 혼 바깥면~연결봉 안쪽면 사이 총4 mm. 와셔 두께를 포함한 길이 |
| 상용 캐스터 체결 볼트·너트 | 2세트 | 홀Ø3.4/간격20. 길이는 실제 캐스터 플랜지 두께에 맞춤 |
| 보드·센서용 나사·스페이서 | 별도 | 위 구조용 수량에 포함하지 않음 |

M3 너트는 대변5.5, 높이2.4를 기준으로 포켓을 대변5.8, 깊이2.6으로 만들었다. M2.5 일반 너트의 기준 치수는 대변5, 높이2이나 잠금 너트는 더 높을 수 있다. [DIN 934 제조사 치수표](https://www.kotadiafasteners.com/technical-data/din-934-specifications/)

접시머리는 모델 홈의 최대 Ø6.6/깊이1.6 안에 실제 머리가 잠기는지 시험한다. 와셔를 추가하면 필요한 나사 길이가 달라진다. **링크 핀 길이는 무조건 늘리지 않는다.** 특히 위쪽 핀이 길어 오른쪽 가이드까지 돌출되면 걸릴 수 있다. 기본 볼트 유효 길이14 mm를 기준으로 실제 너트와 끝 돌출을 확인한다. 혼의 핀 구멍이나 재질이 맞지 않으면 약한 플라스틱 혼을 억지로 넓혀 사용하지 말고 적합한 혼/링크 규격으로 다시 설계한다.

혼 뒤쪽 핀 머리 검사는 외경4.5/두께2.5 mm의 명목 형상을 기준으로 했다. 이보다 큰 머리는 별도 확인해야 한다. 일반 M3 소켓머리 검사는 외경5.5/높이3 mm 기준이며, 실제 제품 머리·와셔가 더 크면 주변 간격을 다시 확인한다.

가이드·서보의 M2.5 6곳은 플라스틱 파일럿 체결이다. 초기 구멍Ø2.0을 출력하고 실제 공정에 맞게 약Ø2.05로 정리한 뒤 M2.5×0.45 탭을 낸다. 탭·드릴 규격은 [미터 나사 가공 치수표](https://taurusfix.com/standards/din-934)의 M2.5 행을 참고했다. 부품이 갈라질 정도로 조이지 않는다. 자주 분해할 양산 구조에서는 인서트/관통 너트 체결로 다시 바꾸는 것이 좋다.

필요 공구: 프린터·슬라이서, 버니어캘리퍼스, 맞는 드라이버, 니퍼, 디버링 도구, 수동 드릴/리머, M2.5 탭, 스트랩. 금속·전기 부품과 공구는 STL에 들어 있지 않다.

## 5. 출력 설정과 후처리

- 가정: 0.4 mm 노즐 FDM. 시작값은 레이어0.2 mm, 벽4줄, 상·하단5층, 내부 채움 약30%. 프린터/재료 검증값이 아니라 시험 시작값이다.
- 치수 공차와 인성·온도 조건에 맞는 재료를 선택하고, 재료 제조사의 온도 설정을 따른다. 시험편과 본체의 재료를 바꾸면 공차 시험도 다시 한다.
- 표에 표시한 부품에는 국부 서포트가 필요하다. 특히 `04_gate_slider`의 슬리브가 허공에서 시작하지 않도록 슬라이서의 레이어 미리보기로 확인한다. 전체가 무서포트인 설계가 아니다.
- 가이드 홈, 너트 포켓, 접시 홈을 서포트가 막지 않도록 한다. 2.6 mm 높이의 측면 너트 통로가 닫히지 않았는지 확인한다.
- 부품 바닥은 Z≈0이다. 계산 오차로 하부 프레임에 약0.000001 mm 이하 음수가 보일 수 있으며 슬라이서의 ‘베드에 놓기’로 처리한다. 크기는 변경하지 않는다.
- 모든 날카로운 버·실·서포트를 제거한다. 슬리브는 기존0.4 mm/면 여유를 기준으로, 캡 소켓은0.3 mm/면 여유다. 억지로 끼우거나 서보 힘으로 마찰을 이기게 하지 않는다.
- M3 통공은 기본Ø3.4, 너트 포켓은 대변5.8. 먼저 시험편에서 맞는지 확인하고, 맞지 않으면 설계 파라미터/출력 보정을 바꾼 뒤 다시 내보낸다.

## 6. 조립 순서

1. **시험편과 실물 부품 대조.** 모터 마운트·서보 받침·캐스터 브래킷을 먼저 시험 출력하는 것도 좋다. 맞지 않으면 큰 셸과 하부 전체 출력을 보류한다.
2. **너트 자리 준비.** 셸의 뚜껑 보스는 안쪽 옆 입구로4개, 하부 결합 보스 위쪽4개, 데크 받침 아래4개를 넣는다. 모터 마운트 각2개는 귀 옆 입구로, 배터리 트레이4개는 기둥 앞/뒤 입구로 넣는다. 캐스터 브래킷 후면 체결용2개는 안쪽 육각 홈에 넣는다. 처음에는 접착제를 쓰지 말고 볼트가 수직으로 들어가는지 확인한다.
3. **하부 가동부 삽입.** 가이드 캡과 서보 받침을 떼어둔 상태에서 통합 게이트 슬라이더를 두 가이드 위에서 동시에 내려 끼운다. 캡2개를 장착하고 M2.5×10으로 고정한다. 게이트가 DOWN~UP 전 구간을 손으로 부드럽게 움직여야 한다.
4. **서보 받침 고정.** 낮아진 두 지지대에 받침 팔을 올리고 M2.5×10 두 개로 고정한다. 서보 몸체를 넣고 클램프/얇은 패드를 올린 뒤 M2.5×10 두 개로 가볍게 잡는다. 귀·선·축이 눌리면 중단하고 실측 반영한다.
5. **혼·연결봉 장착.** 실제 서보 중립을 확인하고 맞는 혼을 장착한다. 위쪽 혼 핀은 반경8, 아래 러그와 연결봉 축간은21. 위쪽에는 총4 mm 스페이서, 아래 러그 바깥면과 링크 안쪽에는 약0.75 mm 공간이 있다. 와셔를 넣고 약0.2~0.3 mm의 자유 회전 여유를 남기며 잠금 너트를 조정한다. 링크를 볼트로 꽉 눌러 고정하지 않는다.
6. **모터와 데크.** 모터를 바깥쪽에서 크래들에 밀어 넣어 각2개 타이로 묶는다. 좌우 크래들을 데크에 각각 M3×12 두 개로 체결한다. 손으로 축을 돌려 간섭과 흔들림을 확인한다.
7. **배터리 트레이와 데크.** 트레이4개 기둥을 데크에 M3×12 네 개로 고정한다. 배터리는 레일 위에 놓고 스트랩2개로 고정한다. 셀·보호회로·전선에 나사 끝이 닿지 않아야 한다.
8. **캐스터와 셸.** 실측한 캐스터를 브래킷에 장착한다. 플레이트 위의 체결 너트가 높이 Z=18 이상으로 올라와 후면 보강부에 걸리지 않게 한다. 브래킷은 셸 후면에 접시머리 M3×10 두 개로 고정한다. 기본 상면 공간이 좁으면 다른 캐스터/볼트 패턴에 맞춰 재설계한다.
9. **데크와 셸.** 데크를 셸 받침4곳에 M3×10 네 개로 고정한다. 보드/드라이버는 실제 홀에 맞는 어댑터와 절연 스페이서로 장착한다. 뒤쪽 Ø7 개구3개와 큰 프레임 창으로 배선을 빼고 링크 경로 밖에 고정한다.
10. **상·하부 결합.** 셸을 가이드/서보 기둥 위로 내린다. 하부 X=±44, Y=17/-38의4점에 아래에서 접시머리 M3×20을 넣어 상부 너트에 체결한다. 나사 머리가 바닥 아래로 튀어나오지 않아야 한다.
11. **바퀴와 마지막 검사.** 허브와 바퀴를 장착하고 바닥 접촉을 맞춘다. 전원 OFF에서 게이트 전 구간·배선·볼트 끝·캐스터 하우징·바퀴 회전을 다시 확인한다. 뚜껑은 접시머리 M3×10 네 개로 고정한다.

배터리 교체는 뚜껑만 열면 바로 위로 빠지는 구조가 아니다. 보드/데크에 접근하고 필요한 커넥터와 트레이 나사를 풀어야 한다. 서보 교체는 뚜껑과 상단 클램프를 열어 진행한다. 가이드 슬라이더를 빼려면 상부와 서보 받침, 가이드 캡을 먼저 분리한다.

## 7. 출력·주행을 보류해야 하는 조건

- 프린터 공차 시험에서 너트가 안 들어가거나 가이드가 걸릴 때.
- 실제 서보의 귀·전체 몸체·전선, 모터 단자, 배터리 포장/보호회로, 캐스터 하우징을 재지 않았을 때.
- 실제 혼/핀 규격이 맞지 않거나 링크 핀 끝이 가이드 쪽으로 돌출될 때.
- 디스크 없이 평평한 바닥에 놓았을 때 앞으로 기울거나 하부0.3 mm 간격이 유지되지 않을 때.
- **무게중심 문제:** 바퀴 축은 Y=-15, 후방 캐스터는 Y=-40. 무게중심 투영이 지지 삼각형 안에 있어야 한다. Y 무게중심이 -15보다 앞이면 앞쪽으로 기울 수 있다. 전방 구조·셸 질량 때문에 이 가능성이 있어, 배터리 배치/구동축을 실물 질량에 맞춰 다시 조정할 수 있다.
- 대회가 바퀴까지 포함해 폭100 mm를 요구할 때. 현재 셸100×100×100, **바퀴 포함 폭126 mm**다.

무게중심·마찰·모터 토크·재료 강도는 CAD 간섭 검사의 통과 여부와 별개다. 낮은 속도, 무부하에서 시작해 디스크 포획·전진·후진·회전·바닥 이음부를 단계적으로 시험한다. 미확정 항목을 “바로 출력하면 무조건 작동한다”는 의미로 해석하지 않는다.

## 8. 완료한 CAD 검사와 한계

- 본체용 13종과 시험편 2종, 총 15개 STL이 모두 닫힌 단일 연결 형상이다.
- 명목 형상 기준 17개 간섭 검사를 통과했다. 의도한 받침면 접촉을 제외한 고체 겹침은 없었다. 게이트 UP/DOWN, 상부에 대한 이동 영역, 연결봉의 보수적인 전체 이동 범위, 혼 뒤 핀 머리 회전 영역과 체결 공간을 포함한다.
- 링크 운동을 양 끝점을 포함한 189개 위치에서 검사했다. 축간21 mm, 게이트 이동11.7 mm가 유지됐고, 구간 전체에서 이동 방향이 역전되지 않는 수학적 조건과 가이드 끝 여유도 확인했다.
- 이 결과는 설정된 CAD 치수에 대한 검사다. 실물 부품 형상, 프린터 오차, 마찰, 강도, 서보 각도 보정, 실제 디스크 포획 성능이나 전복 안정성을 보증하지 않는다.

검사 결과와 형상 수치는 `verification_v0.7.json`에 기록했다. 소스는 `hamster_print_ready_v0.7.scad`이며 원래 조립 좌표계(+Y 전방, 바닥Z=0)를 유지한다. 부품 STL만 베드에 놓기 편한 방향으로 이동/회전했다.
