# 전체 작업 완료 시간 개선 — 2026-09-07

대상은 기존 공개 시뮬레이터의 햄스터 1대, 비버 3대, 선택형 박쥐 드론이다.
기존 공개 버전의 공통 경로 최적화가 켜진 실행을 기준으로 비교했다.
모든 지상 로봇이 집기·배치·해제 확인·후퇴·주차까지 완료한 시각을 측정했다.

| 최종 점수 | 160점 | 160점 |

| 총 지상 이동 | 19.7324m | 17.3712m |

완료 시간은 10.94초, 약 18.9% 감소했다. 로봇 대기 시간 합계는 동시에
기다리는 로봇이 있으면 중복 합산되므로 경기 시간과 동일한 값이 아니다.

## 새 동선

| 로봇 | 출발 | 실제 물체 운반 순서 | 주차 완료 |
| --- | ---: | --- | ---: |
| B1 한가한 비버 | 0초 | C1 → C2 → G1 → R1 → Y1 | 39.92초 |
| H1 햄스터 | 0초 | D1 → D2 → D3 | 33.44초 |
| B2 바쁜 비버 | 3초 | C3 → C4 → R3 → G3 → Y3 | 47.06초 |
| H2 식별자의 세 번째 비버(B3) | 7초 | G4 → Y2 → R4 | 46.92초 |

예선 모델의 색별 4개 중 3개를 운반한다는 조건 안에서 G2 대신 G4,
R2 대신 R4를 선택했다. 기존 목적지 슬롯을 유지한다. 디스크 3개,
큐브 4개, 색별 원기둥 3개씩 총 16개 작업을 모두 수행한다.
큐브를 미리 실은 로봇과 탄창 순서는 바꾸지 않았다.

## 계산 방법과 재현

1. 기존 동선을 실제 엔진으로 실행해 기준값을 구한다.
2. 두 줄의 시작 위치에서 출발 간격 후보를 만든다.
3. 비버 간 원기둥 작업 교환·이관, 작업 순서, 출발 시각, 같은 색의
   미선택 원기둥 대체 후보를 만든다.
4. 이동·회전·집기·배치 예상 시간을 합산해 검토 순서를 정한다.
5. 후보별로 동일한 물리·충돌·센서·점수 엔진을 다시 실행한다.
6. 전체 완료, 점수 보존, 충돌 0회, 최소 12mm 간격을 만족하는 후보 중
   가장 이른 종료를 채택한다. 동률이면 이동거리와 대기 시간을 비교한다.
7. 선정된 실제 작업 순서를 고정하고 다시 실행해 결과를 검증한다.

64개 후보 탐색과 추가 24개 후보 독립 재검토에서 위 동선을 얻었다.
이것은 검토한 후보 중 가장 빠른 결과이며 전역 최적해 증명은 아니다.
현재 최선보다 늦은 후보는 조기 중단한다. 탐색 중 계산이 너무 오래 걸리는
후보는 5초 계산 예산으로 중단하고 미완료로 탈락시킨다. 기기 성능에 따라
추가 탐색 결과가 달라질 수 있다. 선정 동선의 최종 검증에는 계산 시간
제한을 적용하지 않는다.

`node --experimental-strip-types tools/optimize-schedule.ts --budget=64`

웹 화면의 '기존 동선 실행', '새 동선 실행'은 같은 정상 조건에서 각각
실제 엔진을 실행한다. '동선 추가 탐색 후 실행'은 별도의 브라우저 작업에서
48개 후보를 검토하며 중단할 수 있다. 결과 수치를 타이머에 하드코딩하지
않는다. 저장된 것은 시작 시각과 작업 계획이며 실제 실행은 매번 계산한다.

현재 참조 배치와 다른 물체 위치·로봇·작업·센서 조건에는 저장 계획을
자동 적용하지 않는다. 실행 도중에는 새 계획을 덮어쓰지 않는다.

## 관측 조건별 검사

정상 조건에서는 드론 없음·중앙 관측·이동 관측 모두 47.06초다.
10초마다 1.2초씩 B3 기본 입력을 끊는 모의 시험에서는 드론 없음 52.02초,
드론 보조 관측 47.06초다. 모두 160점, 충돌 0회를 확인했다.
추가로 입력 지연·오차·전체 누락·비상정지·5대 혼잡 시험을 검사한다.

속도 0.22m/s, 회전 2rad/s, 조작 시간, 로봇 외곽, 12mm 안전 간격과 채점
조건을 줄이거나 생략하지 않았다. 실제 구현 전의 메카넘 이동·이상적인
기구 및 좌표 모델이다. 실물 2륜 차동구동의 이동시간 또는 실측 성능을
보장하지 않는다. 한국 예선 첨부 배치 확정과 실물 기구·모터·센서 보정 후
동일한 탐색을 새 모델에서 다시 수행해야 한다.
