# 의료키트 1·2·1 전담 배송과 동선 재계산 — 2026-09-07

햄스터 H1 1대와 비버 B1/B2/B3 3대, 선택형 박쥐 드론을 유지한다.
B3의 내부 ID는 기존 태그·로그 호환을 위해 H2 그대로다. 실제 장비에는 연결하지 않는다.

## 사전 적재와 목적지

| 비버 | 의료키트 | 개수 | 전담 목적지 |
| --- | --- | ---: | --- |
| B1 한가한 비버 | C2 | 1 | 왼쪽 PCC-L |
| B2 바쁜 비버 | C1, C3 | 2 | 병원 H |
| B3 세 번째 비버 (내부 H2) | C4 | 1 | 오른쪽 PCC-R |

한 목적지의 의료키트는 한 비버만 운반한다. B2는 두 키트를 병원 내 서로
다른 슬롯에 순서대로 배출하며, 한 번에 두 개를 떨어뜨린 것으로 처리하지 않는다.
키트 ID·최종 배치 슬롯·채점은 유지한다. 각 비버는 적재 키트를 모두 배송한
다음 원기둥 작업을 한다. 최적화와 추가 탐색도 키트 담당·적재 순서를 바꿀 수 없다.

원기둥은 이 전담 제약의 대상이 아니다. 기본 계획은 R2를 B2, Y3를 B3에
배정하고 B2/B3의 주차 위치를 병원 쪽/오른쪽으로 조정했다.
기존 2·2·0 계획의 원기둥 배분과 주차를 그대로 쓰면 목적지 예약과
정지 로봇이 서로 막는 경우가 있어 전체 임무를 다시 검증했다.
햄스터 작업과 속도·기구 동작 시간·충돌 여유는 변경하지 않았다.

집기·해제 확인·후퇴·모든 로봇의 주차까지 완료한 시각을 측정한다.

드론만으로 속도 보너스를 부여하지 않는다. 가림·누락 시험은 별도 조건이다.

## 선정된 동선

| 로봇 | 출발 | 실제 운반 순서 | 주차 완료 |
| --- | ---: | --- | ---: |
| B1 | 0초 | C2 → G1 → R1 → G2 | 45.14초 |
| H1 | 0초 | D1 → D2 → D3 | 29.62초 |
| B2 | 2초 | C1 → C3 → R3 → G4 → R4 | 42.30초 |
| B3 (H2) | 6초 | C4 → Y3 → Y1 → Y2 | 45.18초 |

G3 대신 G4, R2 대신 R4를 같은 색 안에서 선택하고 기존 목적지 슬롯은 유지한다.
노랑은 여전히 PCC-L에 Y1, PCC-R에 Y2/Y3을 배치한다.
전체 작업은 디스크 3개·의료키트 4개·색별 원기둥 3개씩 총 16개다.

## 재현·검증

`node --experimental-strip-types tools/optimize-schedule.ts --budget=64`

64개 후보를 실제 엔진으로 비교했다. 저장한 것은 수치 타이머가 아니라
작업 계획이며 실행마다 다시 계산한다. 현재 최선보다 늦거나 충돌·미완료인
후보는 탈락한다. 후보별 탐색 계산 예산은 5초, 최종 재검증에는 계산 시간
제한이 없다. 기기 성능에 따라 탐색 결과는 달라질 수 있으며 전역 최단 보장은 아니다.
웹의 추가 탐색은 검증된 계획을 시작 후보로 사용한다.

검사는 적재 1·2·1, 목적지별 단독 소유, 키트 우선 배출, 원기둥 역할·색·슬롯,
드론 유무, 전체 점수·접촉·연속 이동, 입력 누락·비상정지, 저장 계획 재현을 포함한다.
다른 로봇에 키트를 넘기는 잘못된 계획은 적용 전에 거부하며 시작한 임무에는
계획을 덮어쓰지 않는다.

5대 지정 시험은 기존 비버들의 키트 담당을 그대로 두고 추가 비버에 G2만
배정한다. 병원 키트보다 먼저 원기둥을 놓아 진입을 막지 않도록 녹색 작업을
선택했다. 지정 배치에서 53.96초/160점·충돌 0회이며 임의의 5대 이상 배치에
대한 보장은 아니다. 5대는 드론 없는 별도 혼잡 시험이다.

모델은 0.22m/s 메카넘 이동·회전 2rad/s·12mm 안전 간격의 이상적 모의다.
실제 2륜 차동 로봇 성능이나 실전 최단 시간을 보장하지 않는다.
경기장 좌표는 기존 잠정 연습 장면 그대로다. 공식 확정 배치와 실물 보정 뒤 재탐색해야 한다.
