# Robo 6대 경기 시뮬레이터

경기장 `1,143×1,181mm`, 출발구역 `480×280mm`, SCAD 명목치로 계산한
바퀴 포함 운용 외형 `126×100×100mm`를 반영한 브라우저 시뮬레이터다. 현재 SCAD의 차동구동과
4륜 메카넘 개조안을 같은 화면에서 비교한다.

## 실행

Node.js 22.13 이상과 pnpm을 준비한 뒤:

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:3000`을 연다.

## 검증

```bash
pnpm test
pnpm lint
pnpm build
```

테스트는 다음을 확인한다.

- SCAD 외곽선이 정확히 126×100mm인지
- 6대의 고정 방향 3×2 시작 배치가 출발구역 안에서 겹치지 않는지
- 메카넘 전진·횡이동 휠 부호가 맞는지
- 임시 6경로를 100Hz로 120초 재생했을 때 충돌 없이 6대가 도착하는지

## 조작

- `자동 경로 시작`: 충돌 검증용 결정론적 경로 재생
- `메카넘 개조안 / 현재 SCAD`: 홀로노믹·차동구동 비교
- `R1~R6`: 로봇 선택
- `수동 제어`: W/S 전후, A/D 좌우, Q/E 회전
- 차동구동에서는 실제 구조와 같이 A/D가 비활성화됨
- `0.25×~4×`: 재생 속도
- 격자, 계획 경로, 주행 궤적, 81mm 회전 안전원 표시 전환

## 정확도와 한계

충돌은 63mm 원이 아니라 SCAD 명목치로 계산한 바퀴 포함 외형의 보수적
8각형 볼록껍질을 로봇 자세대로 변환해 SAT와 다각형 간 거리로 계산한다.
차동구동은 원본 SCAD의 차축 외곽을, 메카넘 개조안은 앞뒤 4개 휠의
12×25mm 가상 외형을 모두 감싸는 별도의 대칭 8각형을 사용한다.
두 모델의 전체 폭·길이는 같지만 모서리 형태가 달라 충돌 계산도 구분한다.
100Hz 고정 스텝을 사용하고, 벽·차체·장애물과의 간격이 15mm 아래로
내려가려 하면 해당 로봇을 정지시킨다. 출력·조립 뒤 실측 보정이 필요하다.
이 검사는 각 10ms 스텝의 끝점 기준이며 연속 swept collision은 구현하지
않았으므로 실물 안전을 보장하지 않는다.

공식 자료실에서 예선 맵 전체도와 게임 요소 고정 배치도는 아직 배포 전이다.
따라서 경기장·출발구역은 공개 규격을 반영했지만, 붉은 장애물·목표·경로는
알고리즘 검증용 임시 배치다. 화면과 문서에서 이를 실제 공식 배치처럼 표시하지
않는다.

이 웹앱은 서버나 실물 로봇에 명령을 전송하지 않는다. 시뮬레이션이 통과해도
실물 안전성은 보장되지 않으며, 실측·1대 HIL·2대 교차·6대 순차 시험이 필요하다.

차동구동 비교 모드는 메카넘용으로 만든 같은 임시 경로를 사용한다. 좁은
공간에서 회전해야 하므로 일부 로봇의 15mm 안전정지는 의도된 비교 결과이며,
차동구동용 최적 경로의 성능 측정이 아니다.

상세 기구·전자 적용안은 [`../docs/RC_MECANUM_ADAPTATION_KO.md`](../docs/RC_MECANUM_ADAPTATION_KO.md)를 참고한다.
