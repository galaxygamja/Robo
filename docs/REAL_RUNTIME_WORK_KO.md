## 구현 결과와 파일 소유 범위

- `vision/detection.py`: 기존 검출 CLI와 runtime의 공통 실제 이미지 처리 경로.
  기존 preview/track 동작은 유지하고 중복 검출 로직만 분리했다.
- `runtime.py`: 고정 USB/영상 파일 CLI, 설정 복사본 고정, 별도 영상 프로세스,
  중앙 감시, 시작/종료/오류 정리. 실제 모터/무선 송신은 만들지 않았다.
- `runtime_session.py`: 기존 tracker/controller 재사용, 200ms 관측 만료,
  새 프레임 없는 tick의 TTL 재발행 금지, 3프레임 재확인과 종료 잠금.
- `runtime_io.py`: 256KiB 최신 JSON 공유 메모리, 무대기 잠금,
  128행 제한 비동기 기록, 기존 파일 덮어쓰기 금지.
- `runtime_report.py`: 단일 세션/시각/출력 등록/최종 0 검사와 호스트 지연 집계.
- `control_loop.py`: 선택적 경기장 크기와 네 외벽 차체/제동 영역 검사 추가.
- `ObjectTracker.poll`: 프레임 사이 감시가 연속 확인을 깨지 않도록 분리.
  실제 잘못된 입력은 물체 집기 근거도 즉시 무효화한다.
- `config/runtime_goals.example.json`: 빈 목표 예제. 목표 없는 기본 실행은 전부 0.
- `tests/test_runtime*.py`, `tools/verify_camera_runtime.py`: 새 통합/고장 시험.
  CI 기존 전체 시험에서 자동 실행하고 wheel/sdist CLI smoke도 추가했다.
